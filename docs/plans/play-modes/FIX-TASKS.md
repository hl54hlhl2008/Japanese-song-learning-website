## T1 · 等待音频元数据时的循环开关即时生效

**目标**　用户在单句等待音频元数据时打开或关闭循环，首个播出的片段按开始播放前最后一次选择执行。

**允许改的文件**

- `src/App.jsx`

**验收**

- 在 `ae292bf` 与修复版本上分别执行下方浏览器步骤，覆盖「开 → 关」和「关 → 开」。使用 15 秒音频，歌词分别从 2、6、11 秒开始。
- 原版本「开 → 关」仍从约 5.5 秒到 11 秒循环，「关 → 开」在 11 秒停止。修复后，「开 → 关」在 11 秒停止且清除播放标记，「关 → 开」从 11 秒跳回约 5.5 秒继续播放且保留标记。
- 运行 `node --test tests/*.test.mjs` 和 `npm run build`，原有 63 项测试与构建均通过。

**浏览器复现步骤**

1. 在支持开发者工具的浏览器打开测试歌，选择「单句」。等待音频实际就绪，在控制台确认 `document.querySelector('audio').readyState >= 1`。按本次测试方向设好循环的初始状态，然后执行：

   ```js
   window.utaPendingAudio = document.querySelector('audio')
   Object.defineProperty(window.utaPendingAudio, 'readyState', { configurable: true, value: 0 })
   window.utaPendingAudio.load = () => {}
   ```

2. 点击第 2 句右侧的播放按钮，再切换循环开关。此时音频应保持暂停。恢复真实媒体属性并手动触发一次元数据事件：

   ```js
   delete window.utaPendingAudio.readyState
   delete window.utaPendingAudio.load
   window.utaPendingAudio.dispatchEvent(new Event('loadedmetadata'))
   delete window.utaPendingAudio
   ```

3. 观察第 2 句到达 11 秒时是暂停还是跳回约 5.5 秒。刷新页面后重新设定初始开关，验证反向切换。

**依赖**　无。

**验证方式**　浏览器实测修复前后两个方向，记录句尾行为。运行全量测试和构建。

## T2 · 新模式的播放终点受音频时长限制

**目标**　使用「从开头播放到当前句」播放已知时长不足 0.12 秒的音频时，片段终点截断到音频时长。

**允许改的文件**

- `src/lib/playbackModes.js`
- `tests/playbackModes.test.mjs`

**验收**

- 用 `node --test tests/playbackModes.test.mjs` 覆盖已知时长为 0、0.08、0.119、0.12 和 0.121 秒的末句。片段起点为 0，终点分别等于实际时长。0.12 秒为分界，低于该值时音频时长优先，达到该值时可满足 0.12 秒下限。
- 测试已知时长为 0.08 秒且下一句时间戳为 0.05 秒的情形，终点为 0.08 秒。普通音频仍可使用 0.12 秒下限，时长未知的末句仍由音频自然结束。
- 运行 `node --test tests/*.test.mjs` 和 `npm run build`，原有 63 项、边界用例及构建均通过。

**依赖**　无。

**验证方式**　运行纯函数边界测试、全量测试和构建。

**目标**　新模式的提示明确说明点歌词行的播放按钮可起播，并注明手机网页也可点整句。

**允许改的文件**

- `src/App.jsx`

**验收**

- 在有音频的网页歌词列表选择「从开头播放到当前句」。将视口设为 651 px，提示应把整句点击限定为手机网页。点击第 2 句正文时只选中该句，点击右侧播放按钮时从 0 秒起播。
- 停止第 2 句播放后将视口设为 650 px，点击第 2 句正文时从 0 秒起播。确认提示中的两种入口与实际行为相符。

**依赖**　同一 worktree 中，依赖 T1 验收后的 `src/App.jsx`，避免两个任务并发改写该文件。

**验证方式**　浏览器实测 650 px 和 651 px 两侧的文案和点击动作。运行全量测试和构建。

## 记账

| 既有缺陷 | 触发条件 | 现象及影响面 |
| --- | --- | --- |
| 单句同时间戳 | 两句都在 6 秒开始，选择靠前一句并开启单句循环 | 片段为 5.5–6 秒，持续重复目标句前的音频。影响含相同时间戳的单句循环。 |
| 越界末句循环 | 音频时长 15 秒，末句标为 16 秒，开启单句循环 | 计算得到起点 15.5 秒、终点 15 秒，音频结束时会尝试回到越界起点。影响带越界末句的单句循环。 |
| 暂停时旧播放结果恢复标记 | A 正在播放，点 B 后其 `play()` 尚未返回，此时再次点仍显示为播放中的 A | 音频暂停后，B 的迟到结果可能恢复播放标记。影响快速换句后暂停时的状态反馈。 |
